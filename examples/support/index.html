Support page

A support page is a post like any other: one event of its owner (kind 30078) made with a manifest, here support-v1 below. Its fields are plugins: a Markdown intro, payment (Lightning zaps and invoices, on-chain Bitcoin) and links (tip pages as their own buttons). viewLayout: 'cards' shows the ways to pay as one grid of cards. Every link and code has a ⋯ menu (QR, copy, share, open).

WorldTrip's support page

The options of worldtrip.guide/support, shown by <nostr-post-view> from values given here (nothing published). Without an author, the Lightning address pays with a plain invoice, not a zap.

Behind a button

<np-dialog-button> opens anything in a dialog, here the same page.
